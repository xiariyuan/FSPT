## Likely remaining cause

The old cache was generated by repo-native `evaluation.eval`, which saved `.npz` files. The old `.npz` files contain only:

```text
tracks
visibility
```

They do not contain logits.

The old `.npz` exactly matches the old unified bridge:

```text
tracks diff = 0
visibility diff = 0
```

Since the current reproduced inference still differs from the old `.npz`, remaining differences likely come from the exact repo-native evaluator path, dataloader preprocessing, or runtime details that our hand-written mirror still does not fully reproduce.
