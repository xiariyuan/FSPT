# Route-D MUSR temporal-v0 Stage-A result — 2026-07-17

## 1. Claim boundary

This is a selector-only Kubric model-validation result. It is not a learned
state-write result, a final synthetic holdout result, or an external TAP-Vid
result. Calibration, final_holdout, DAVIS, and the official 1,144-sample
Kinetics evaluation were not read or rerun.

## 2. Frozen experiment

Temporal-v0 preserves the frozen CoTracker3 backbone, all six candidate
coordinates, raw-v1 601-D candidate features, raw-v1 160-D state features,
fit/model-validation identities, optimizer, seed, and gates. The only controlled
change is a fixed six-frame causal rank-invariant set-evidence accumulator.

The model:

- pools each past candidate set without treating correlation rank as an identity;
- uses two causal temporal Transformer layers;
- masks all pre-query padding and all future frames;
- scores only the current frame candidates;
- retains exact zero-step native fallback;
- does not train abstention or state-write heads.

## 3. Structural audit

The implementation passes:

- exact zero-step candidate-0 selection and coordinate parity;
- no fully masked attention rows and no NaNs;
- strict future-frame exclusion;
- pre-query padding isolation;
- past non-native candidate permutation invariance;
- current non-native candidate permutation equivariance;
- exact fit-normalization equivalence to raw-v1 Stage A;
- deterministic monotonic threshold construction without CUDA cumsum;
- gradient flow into the temporal encoder after native-safe output-head warmup.

## 7. Scientific interpretation

The frozen pool still has `+6.8463 AJ` coordinate-oracle headroom, but three
selector families recover essentially none of it:

| Selector representation | AJ gain |
|---|---:|
| structured 64/32 | +0.0173 |
| raw single-frame 601/160 | -0.0149 |
| causal temporal-v0 | +0.0041 |

The temporal module is not simply overaggressive: harmful selections are very
rare and the severe tail improves. Its failure is insufficient recall. The
current candidates are generated by an uncalibrated frozen correlation ranking,
while all learned modules are asked to infer correctness after those hypotheses
have already been discretized. Adding more selector features or another temporal
window is therefore not justified.

The next scientifically distinct route changes candidate generation and dense
correlation supervision while preserving the frozen backbone and native fallback.
